# Cómo contribuir a proyectos y comunidades abiertas
Diapositivas para el taller de contribuir a open source software con foco en R

Por Yani Bellini Saibene

## Descripción

Este repositorio contiene las diapositivas en español del taller sobre contribuciones a proyectos y comunidades de código abierto, basado en el contenido del [Programa de Campeones de rOpenSci](https://github.com/ropensci-training/osscontribution).

## Contenido

Las diapositivas cubren:

* Qué es una contribución para un proyecto de código abierto
* Contribuciones desde la perspectiva de una comunidad
* Modelos de participación (Pathway To Inclusion, Modelo CSCCE)
* Ejemplos de rOpenSci
* Cómo hacer que tu paquete sea amigable para contribuciones

## Cómo generar las diapositivas

Este es un proyecto de Quarto. Para generar las diapositivas:

1. Instala [Quarto](https://quarto.org/docs/get-started/)
2. Abre el proyecto en RStudio o ejecuta desde la línea de comandos:
   ```
   quarto render index.qmd
   ```

Las diapositivas se generarán en formato HTML usando Reveal.js.
